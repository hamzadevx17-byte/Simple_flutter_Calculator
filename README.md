# Simple Flutter Calculator

A clean and simple Calculator application built using **Flutter** and **Dart**. This is my very first hands-on project created to test and showcase my basic Flutter development skills, state management, and UI design capabilities.

## ✨ Features
* **Addition (+)** and **Subtraction (-)** operations.
* User-friendly and clean Interface.
* Responsive design for mobile screens.

## 🚀 What I Learned
* Designing layouts using Flutter widgets (Rows, Columns, and Buttons).
* Handling user input and updating the UI dynamically (setState).
* Structuring code for basic mathematical logic.

## 🛠️ How to Run
1. Clone this repository: `git clone https://github.com/hamzadevx17-byte/Simple_flutter_Calculator.git`
2. Navigate to the project folder: `cd Simple_flutter_Calculator`
3. Run the app: `flutter run`
